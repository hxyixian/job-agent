# Job Agent — AI 求职助手

一个本地运行的 AI 求职 Agent：自动在招聘平台（当前支持 Boss直聘）筛选职位、投递沟通、AI 辅助回复 HR，并按风险分级推送告警（飞书 / 邮件）。

> **项目状态**：开发中 —— 阶段一（需求）定稿并通过门禁评审（3 轮）；阶段二（设计）文档已产出待审阅：设计文档、开发文档（Stage 1-7）、验收文档。详见 [Document/Update](Document/Update/)。

## 功能概览（v1.0.0 规划）

- **简历驱动**：上传简历 → AI 分析 → 生成建议职位方向 → 用户确认
- **自动投递**：规则筛选（城市/薪资/规模/排除项）→ AI 匹配评估 → 固定招呼语投递；三级频率控制（随机延时 / 每小时 / 每日上限）
- **AI 回复 HR**：低风险消息自动回复，关键消息（薪资/面试时间）草拟进待发箱人工确认；多模态消息转人工
- **分级告警**：高/中/低三级，飞书机器人 Webhook + 邮件（仅高风险）+ 控制台通知中心
- **统计看板**：投递记录、回复率、匹配度分布、公司去重（默认永久拉黑）
- **多站点扩展**：`SiteAdapter` 抽象接口预留其他招聘平台适配
- **本地 Web 控制台**：FastAPI，浏览器访问 localhost

技术栈：Python 3.10+ / Playwright / FastAPI / OpenAI 兼容 API（DeepSeek、GLM、通义等）/ SQLite / pytest / uv（包管理）。

## 快速开始

开发中，暂不可运行。交付后使用 [uv](https://docs.astral.sh/uv/) 管理依赖与 Python 版本（`uv sync` 一键恢复环境），并另行导出 `requirements.txt` 备用。

- 运行数据（投递/会话/告警记录）仅存于本地 SQLite
