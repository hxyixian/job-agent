## SubStage: S5a FastAPI 骨架与安全加固

- 依赖前置：S1a ｜ 并行：**可提前开工**（不必等 S4）｜ 所属阶段：阶段三 - 开发

### 任务内容
1. `console/app.py`：FastAPI 装配（uvicorn 副线程）；**加固六项** [S1/G8]：仅 127.0.0.1；Host 校验中间件（∈{localhost,127.0.0.1} 否则 403）；非 GET 要求 `X-Job-Agent: console` 头；GET 无副作用；敏感字段打码（****尾4位）；**不注册 CORSMiddleware + OPTIONS 预检一律 405/403 + Origin 头校验（存在时必须空或同源）**。
2. 引擎指令队列（线程安全）与 DB 只读快照层。
3. 测试（httpx）：六项加固逐项正反例 [A-CORE-14]。

## SubStage: S5b 页面组①（配置与内容类 5 页）

- 依赖前置：S5a ｜ 并行：与 S5c 并行 ｜ 所属阶段：阶段三 - 开发

### 任务内容
静态页 + `/api` 对接（原生 fetch，每页 ≤300 行 JS）：
1. **简历与方向**：上传（.pdf）、结构化查看/**行内编辑**（FR2.5）、方向生成/编辑/确认（FR2.2/2.3，换简历联动提示）；
2. **招呼语工作台**：双模板（active/passive）各 3 候选→定稿 1；FR5.3 未定稿提示；**主动模板"已同步到平台设置"确认勾选（与模板内容哈希绑定，模板修改自动失效 [F1]）+ 一键复制文案 + 同步指引（平台路径【消息通知-设置招呼语】）**；
3. **任务配置**：四节配置（delivery/messaging/match/notify/ai）表单 + 保存（全量重写提示）+ browse_limits 显示"每日实际投递上限推算" [G3]；
4. **通知配置**：飞书（webhook/secret/级别）、邮件、免打扰、**测试发送**按钮（假端点/真实可选）；
5. **AI 配置**：端点/模型/密钥（打码回显）/**连通性测试**。

### 验收标准
对应 API 全通；表单校验与配置模型一致（auto_reply_limit 下限 1 [A2]）。

## SubStage: S5c 页面组②（运行与操作类 4 页）

- 依赖前置：S5a ｜ 并行：与 S5b 并行 ｜ 所属阶段：阶段三 - 开发

### 任务内容
1. **总览 dashboard**：引擎状态（运行/暂停/熔断原因色块）、前置条件清单（缺项亮红+指引 [B14]）、告警横幅（登录失效/风控/EVICTED/平台限额红条）、dry_run 显著标识、试运行清单入口；控制：start/stop/pause/resume、**登录模式**（打开登录窗口+互斥提示 [M3/G5]）、重新拉起浏览器；
2. **待发箱**：列表（来源/会话/时间/stale 标记）、approve（二次确认+新消息提醒）/edit/skip/regenerate [B10]；
3. **投递记录与看板**：状态筛选+公司搜索、手动标记、统计四指标（§10.4 口径）+分布图；**评估标注视图 + 导出/导入**（want/not_want [G7]）；
4. **通知中心**：全量事件流、级别过滤。

### 验收标准
A-BOOT-1 九页 200 无 JS error；A-CORE-1 页面链路可见。
