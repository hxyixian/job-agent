## 1. 验收范围

**覆盖**：FR1-FR11 全部功能需求、NFR1-8、TEST1-5、浏览器会话层（S1b/Patchright，定型条件 = 第二轮 X4 通过）、Mock 模拟环境、控制台与加固。

**不覆盖**：
- 真实站点的**发送类操作**线上效果——验证上限为只读试运行；发送行为检测在放量期第 1 天人工观察（M5：出现风控信号=暂停+告警+等用户决策）；
- v2 范围（V2-1~V2-7）；浏览器扩展 Adapter（M2 第 3 顺位，默认不开发）；**半自动模式（M5：不进 v1，需要时 v1.x 立项）**；
- HTTP 逆向类通道（v4 决策否决维持 [V8]）。

## 2. 验收环境

| 项 | 要求 |
|----|------|
| 系统 | Windows；**验收前检查**：无远程会话进行中（向日葵/ToDesk 服务停止）；事件查看器无当日新增 WHEA/显卡错误 |
| Python | `.python-version` 锁定的 3.12.x（`uv python list` 一致） |
| 依赖 | `uv sync --locked` 一次成功；`patchright==1.64.4`（不含 playwright 依赖 [K5]） |
| 数据 | 独立测试库与测试配置；**全程不触碰生产库** |
| Mock | `config.site.adapter=mock`；通知走本地假端点（`tests/sim/fake_webhook.py` + aiosmtpd sink） |
| AI | TEST1 全离线（AI 夹具）；TEST2 允许真实 Key（人工触发）；TEST3 试运行用真实 Key |
| 真实账号 | 仅 A-REAL 需要：用户在场配合扫码（登录模式 [M3]）；**验收 Agent 不得执行任何登录或发送操作** |

## 4. 验收项

每项含：目的 / 前置 / 步骤 / 期望（含可观察值）/ 失败标准 / 证据。测试用例均指仓库内 pytest 节点。

### 编译与静态检查层（B17 对照）

**A-BUILD-1 编译等价**
- 步骤：`uv sync --locked` → `uv run python -m compileall src -q`
- 期望：两者退出码 0。
- 失败：任一非零。
- 证据：命令 + 退出码。

**A-BUILD-2 静态检查**：`uv run ruff check src tests` 与 `uv run ruff format --check src tests` 与 `uv run mypy src/job_agent` 均 0 错误 [R6-7]；失败=任一输出错误项；证据同上。

**A-BUILD-3 单测无警告**：`uv run pytest tests/unit -W error` 全绿（豁免白名单在 pyproject 登记）；失败=任一用例失败或警告逃逸；证据：pytest 输出摘要。

### 启动层

**A-BOOT-1 正常启动（Mock）[TEST5]**
- 前置：测试配置、mock adapter、空测试库。
- 步骤：`uv run python -m job_agent` → 浏览器逐一访问 9 个页面（FR11.2 清单）。
- 期望：进程存活；9 页全部 HTTP 200；每页 DevTools console 无 error；`logs/app.log` 无 ERROR/CRITICAL。
- 失败：崩溃 / 任一页 5xx / console error / 日志 ERROR。
- 证据：9 页截图 + 日志片段。

**A-BOOT-2 双实例锁 [B5]**
- 步骤：实例 A 运行中 → 再启动实例 B。
- 期望：B 退出码 2 + 提示"已在运行"；A 的日志无异常、状态 API 正常。
- 证据：两次启动的终端输出 + A 的 /api/status 响应。

**A-BOOT-3 防休眠 [G11]**
- 步骤：引擎进入运行时段 → `powercfg /requests`。
- 期望：出现 SYSTEM 级请求；时段结束后请求消失。
- 证据：两个时刻的命令输出对比。

### 真实环境层（用户协助，TEST3）

**A-REAL-1 只读试运行 [N3，必做]**
- 执行者：**用户 + Agent**（Agent 操作软件，用户扫码与观察）。
- 前置：S1b 定型；无远程会话；显卡驱动无当日 WHEA。
- 步骤：登录模式扫码 [M3] → dry_run 真实运行一轮（浏览放量第 1 档）→ 采集 ≥50 条 JD → 导出脱敏夹具。
- **通过标准（Y3）**：① ≥50 条 JD，每条 jd_text 非空且 ≥100 字符；② 全程零 EVICTED/SECURITY_CHECK/风控信号；③ **零发送证明**：`send_intents` 仅 skipped_dryrun、适配器调用日志无任何 send_* 到达浏览器；④ 浏览计数不超过所在档位。
- 失败/阻塞：任一不满足→记问题清单置顶区；用户不在场→记"阻塞"不得默认通过 [T2]。

- 通过标准：公司名→固定代号（同司同代号）；人名/电话/邮箱/地址替换；"外包/猎头"等特征词保留；diff 人工确认无误报漏报。
